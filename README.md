# Akıllı Broker – telefon uygulaması

Ana ekrana eklenebilen (PWA) mobil arayüz. Bu depoda yalnızca uygulamanın ekran dosyaları vardır; kişisel veri yoktur.
Uygulama, piyasa verilerini ve sanal portföyü kullanıcının kendi gizli deposundan, kullanıcının telefonuna girdiği
erişim anahtarıyla okur. `demo/` klasöründeki veriler sentetiktir (gerçek fiyat değildir).
